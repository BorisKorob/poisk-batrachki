# Поиск батрачки

Тренажёр для подготовки к работе: три трека, 1233 задачи с автопроверкой прямо в браузере.

- **Аналитик данных** — Python (включая декораторы, генераторы, ООП, файлы, регулярки, даты, библиотеки), NumPy, pandas, SQL, теорвер, статистика, A/B-тесты, продуктовые метрики, визуализация, основы ML, собеседование.
- **ML-инженер / Data Scientist** — Python и данные, математика для ML, классические модели, валидация и метрики, признаки и пайплайны, бустинг, кластеризация и PCA, временные ряды, NLP, нейросети, MLOps, собеседование.
- **Аналитик в страховой компании** — основы страхования, заработанная премия и РНП, частота/тяжесть/убыточность, тарификация и GLM, резервы и chain ladder, страхование жизни, ОСАГО/КАСКО и антифрод, МСФО 17 и регулирование.

Общие модули (Python, SQL, статистика) засчитываются во всех треках. SQL выполняется в SQLite (sql.js), Python — в Pyodide с pandas, SciPy, statsmodels, scikit-learn и matplotlib.

## Запуск
- Локально: открыть `index.html` или запустить `.claude\serve.ps1` и открыть http://localhost:8765/.
- В интернете с аккаунтами: см. [SETUP.md](SETUP.md) (GitHub Pages + Appwrite).

## Структура
| Файл | Что внутри |
|---|---|
| `index.html`, `style.css`, `app.js` | оболочка, проверка задач, вход через Appwrite, рейтинг |
| `config.js` | настройки Appwrite (пустой projectId — без аккаунтов) |
| `data.js` | синтетические данные: сервис доставки «Корзинка» и страховая «Надёжный полис» |
| `gen.js` | генераторы вариантов задач и статистические функции |
| `tracks.js` | состав треков |
| `c-*.js` | теория и задачи по модулям |

`#selftest` в адресе прогоняет все эталонные решения через проверку (`#selftest:ins` — только модули с префиксом `ins`).

## Как добавить задачу
В нужный урок файла `c-*.js` добавьте, например:
```js
TK.sql('Название', md`Текст задачи с ‹кодом›.`, md`SELECT ...;`, true)            // SQL, true — порядок строк важен
TK.py('Название', md`Текст`, md`решение`, ['var1', 'f(2)'], { data: ['orders'] })  // Python: сравнение переменных/выражений с эталоном
TK.ch('Вопрос', md`Текст`, ['вариант 1', 'вариант 2'], 1, md`разбор`)               // тест
TK.num('Расчёт', md`Текст`, 0.1234, 0.0001, md`разбор`)                            // числовой ответ
```
